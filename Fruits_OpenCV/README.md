# Purple Fruit Detection
Simple script to highlight the purple fruits in a simulated farm environment that are close to the quadcopter camera.

Uses simple colour as well as area thresholding to identiy the correct coloured fruits at appropriate distance, as well as eliminate the quadcopter props from the detection.
