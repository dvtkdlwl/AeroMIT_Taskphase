# Football Match Analyser using OpenCV
A player-counting script which implements different concepts from OpenCV in order to display the counts of players of each team- blue and red, at the top right.

## Concepts Used:
1. Video capture and frame-by-frame processing
2. Image resizing for performance optimization
3. BGR → HSV color space conversion
4. Color masking and thresholding
5. Contour detection and area-based filtering
6. Bounding box extraction and visualization
7. NumPy-based image manipulation
