# AeroMIT Taskphase
Wide-ranging projects I built during the AeroMIT taskphase 2024-25.

# Domains Covered
## Intermediate Python
1. Data Structures in Python- Lists, Tuples, Dictionaries etc.
2. Object-Oriented Programming
3. NumPy, Pandas, Matplotlib in a Jupyter Notebook Environment

## OpenCV
1. Image Manipulations
2. BGR, HSV, Grayscale color spaces and interconversions
3. Colour Filtering and Area Thresholding
4. Dilation, Erosion
5. Blurring and Smoothing
6. Morphological Transformations
7. Edge Detection, Contouring
8. Template Matching
9. Haar Cascades

## Machine Learning
1. Linear Regression (from scratch & using libraries)
2. Decision Trees

## Deep Learning
Convolutional neural networks built for specific problem statements.

**Real vs Fake Target Detection**: Detects bullseye landing targets from a live camera feed and rejects fake ones. A MobileNetV3 classifier filters out fakes first, then YOLOv8 localises the real targets.

## ROS2
1. Drone Simulations with MAVROS and Gazebo
2. Leader-follower turtles using teleop turtles.
